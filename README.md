## Objetivo

Este repositório destina-se ao desenvolvimento, organização e documentação das atividades práticas da unidade curricular Integração de Sistemas.

## Controlo de versões

O Git permite acompanhar a evolução dos trabalhos, registar alterações e manter um histórico das diferentes versões dos projetos.

## Organização

Ao longo do semestre serão adicionados os trabalhos, exercícios e projetos desenvolvidos na unidade curricular.
